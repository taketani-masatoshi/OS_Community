Demo

Try OrgOS on your Mac

Apple silicon Mac (M1–M4) only.

1. Docker

Download from the official Docker site (Apple silicon).

  1. 1 Download Docker Desktop.
  2. 2 Drag it to Applications.
  3. 3 Open Docker and wait until it starts.

The demo stays inside Docker. It does not change your other Mac folders.

2. Run

Open Terminal, paste these two lines, press Return. 

docker pull --platform linux/amd64 ghcr.io/taketani-masatoshi/orgos-demo:0.8.0-beta.3
docker run --rm --platform linux/amd64 -p 127.0.0.1:9470:9470 ghcr.io/taketani-masatoshi/orgos-demo:0.8.0-beta.3

First run may take a few minutes. This Mac only (127.0.0.1).

3. Open

Chat — http://127.0.0.1:9470/
Wire — http://127.0.0.1:9470/wire/

Stop: Control+C in Terminal.
