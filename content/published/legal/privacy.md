# プライバシーポリシー

最終更新: 2026-06-27

本プライバシーポリシー（以下「本ポリシー」）は、**Southwood Inc.**（以下「当社」）が運営する **OpenOrgOS Community**（https://community.oorgos.org、以下「本サービス」）において、利用者の個人情報等の取扱いを定めます。

本サービスは、組織間通信プロトコル **OpenOrgOS** のオープンソースコミュニティ Web サイトです。当社は個人情報の保護に関する法律（個人情報保護法）その他の関連法令を遵守し、適切に取り扱います。

---

## 1. 取得する情報

当社は、本サービスの提供にあたり、以下の情報を取得することがあります。

### (1) 利用者から直接提供される情報

- コミュニティプロフィール（表示名、専門分野、地域、自己紹介等）
- モジュール役割申請・委員会参加に関する入力内容
- お問い合わせフォーム等を通じた連絡内容

### (2) 外部認証サービス（OAuth）連携により取得する情報

本サービスは、サインインおよびアカウント連携のため、以下の外部サービスを利用します。利用者が連携を許可した場合に限り、当該サービスから情報を取得します。

| サービス | 用途 | 取得例 |
|----------|------|--------|
| Google | OpenOrgOS ログイン ID（主ログイン） | メールアドレス、氏名、プロフィール画像 |
| Microsoft | OpenOrgOS ログイン ID（主ログイン） | メールアドレス、氏名、プロフィール画像 |
| GitHub | 開発者 identity 連携・（設定時）暫定ログイン | GitHub ユーザー ID、ログイン名、メール、プロフィール |
| LinkedIn | プロフェッショナル identity 連携 | LinkedIn メンバー ID、氏名、ヘッドライン、所属、プロフィール URL |

OAuth により取得した情報は、本サービスのアカウント識別、公開プロフィール表示、コミュニティ参加形態の判定に利用します。**LinkedIn 単独でのログインは提供しません**（Google / Microsoft でログイン後の Connect のみ）。

### (3) 自動的に取得する情報

- IP アドレス、ブラウザ種別、OS 等のアクセスログ
- 認証セッション維持のための Cookie および類似技術
- 本サービスの利用状況（ページ閲覧、言語設定等）

### (4) 取得しない情報

- **各社のテナントデータ**（会社内部の運用データ、機密文書等）— 本サービスへアップロードする機能は提供しません
- 本サービスの提供に不要な LinkedIn / GitHub の投稿・メッセージ等

---

## 2. 利用目的

取得した情報は、以下の目的の範囲内で利用します。

1. 本サービスの提供（ユーザー認証、セッション管理、アカウント管理、プロフィール表示）
2. OpenOrgOS コミュニティ identity レイヤー（Community / Professional / Technical）の管理
3. モジュール・委員会・資格認定等のコミュニティ機能の運営
4. Academy（学習・試験）進捗の記録（利用時）
5. 不正利用の防止、セキュリティ維持、障害対応
6. 利用規約違反の調査および対応
7. 本サービスの改善・新機能開発
8. 重要な変更・メンテナンス等の通知
9. お問い合わせへの対応
10. 上記に付随する目的

---

## 3. 第三者提供

当社は、以下の場合を除き、利用者の個人情報を第三者に提供しません。

- 利用者本人の同意がある場合
- 法令に基づく場合
- 人の生命・身体・財産の保護のために必要で、本人同意が困難な場合
- 業務委託先への提供（下記「4. 委託」参照）

公開プロフィール（`/users/{slug}`）に、利用者が設定した範囲の情報（氏名、専門分野、LinkedIn ヘッドライン等）が表示される場合があります。

---

## 4. 委託

当社は、本サービスの運営に必要な範囲で、インフラ・認証・ホスティング等の業務を外部事業者に委託することがあります。委託先に対しては、契約等により適切な安全管理を求めます。

主な委託・利用サービスの例:

- クラウドホスティングおよび CDN
- Google / Microsoft / GitHub / LinkedIn（OAuth 認証）
- データベースホスティング（PostgreSQL）

---

## 5. Cookie 等の利用

本サービスは、ログイン状態の維持、言語設定の保存、セキュリティ（CSRF / OAuth PKCE 等）のために Cookie および類似技術を使用します。ブラウザ設定により Cookie を無効にした場合、ログイン等の一部機能が利用できなくなることがあります。

---

## 6. 保管期間

- アカウント存続期間中、本ポリシーに定める目的のために保管します
- 利用者がアカウント削除または連携解除を行った場合、合理的な期間内に削除または匿名化します（法令上の保存義務がある場合を除く）
- アクセスログ等は、セキュリティおよび運用の目的で一定期間保管した後、削除します

---

## 7. 安全管理

当社は、個人情報への不正アクセス、漏えい、改ざん、滅失等を防止するため、アクセス制御、通信の暗号化（HTTPS）、認証情報の適切な管理、権限の最小化等、合理的な安全管理措置を講じます。

---

## 8. 利用者の権利

利用者は、当社所定の方法により、自己の個人情報について、開示・訂正・削除・利用停止等を求めることができます。OAuth 連携の解除は、本サービス内の **Connections**（`/settings/connections`）または **マイページ** から行えます。

---

## 9. 未成年者

本サービスは、原則として 16 歳以上の方を対象とします。16 歳未満の方が利用する場合は、保護者の同意を得たうえでご利用ください。

---

## 10. 本ポリシーの変更

当社は、法令の改正、サービス内容の変更等に応じ、本ポリシーを改定することがあります。重要な変更がある場合、本サービス上での掲示等によりお知らせします。変更後に本サービスを利用した場合、変更後のポリシーに同意したものとみなします。
