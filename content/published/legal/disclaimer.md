# 免責事項 · 責任分界

最終更新: 2026-06-25

## 1. コミュニティの責任範囲

本コミュニティ（会社OS · 組織OS Community）は **OSS フレームワーク（Steward core · 法域パック · 公式モジュール）の開発・配布** のみを担います。

- ソースコードの公開（read-only clone）
- モジュールガバナンス（スチュワード・コントリビューター管理）
- ドキュメント・参考資格制度の運営

## 2. 各社（テナント）の責任

以下は **各社が自己管理・自己責任** とします:

- `tenants/{id}/data/` · `docs/` に含まれる会社データ
- Mac mini · Synology NAS 上でのデプロイ・バックアップ
- モジュール ON/OFF · 規程施行 · 日常運用の結果
- セキュリティ設定・アクセス制御

**テナントデータをコミュニティサイトへアップロードする機能は提供しません。**

## 3. 野良モジュール

`trust_level: wild` として登録されたモジュールについて:

- コミュニティは **動作保証・セキュリティ監査・保守を行いません**
- 互換性（`steward modules check`）は **利用者・作者の自己責任**
- 接続時に免責同意が必要です

## 4. 参考資格

Steward Operator (SO) · Steward Designer (SD) は **能力の参考表示** です。

- PMP® 等の第三者資格とは無関係
- 法的・契約上の保証を意味しません
- 認定の有無にかかわらず、運用結果は各社の責任

## 5. スチュワードシップ

モジュールスチュワードは **栄誉職** です。個別の税務・法務助言や運用結果の保証を意味しません。

## 6. GitHub 権限

- 一般ダウンロード（public clone）は常に可能
- main への merge · リリース tag · 新規モジュール repo 作成権限はコミュニティが管理

## 7. お問い合わせ

Issues は GitHub リポジトリへ。テナントデータに関するサポートは各社の Operator / 内部 IT が担います。
