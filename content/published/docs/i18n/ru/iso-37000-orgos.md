# OrgOS и ISO 37000

**OrgOS** связывает развёртывание и управление: при **инициализации** цель, роли, надзор и прослеживаемость становятся одной базой.

Эта база поддерживает достоверную **самодекларацию** соответствия **ISO 37000** (*Governance of organizations* — руководство). OpenOrgOS Community не выдаёт сторонние ISO-сертификаты.

## Что даёт сообщество

OpenOrgOS Community — **нейтральный дом** для протокола, модулей, обучения и операторов. Заявления об управлении остаются ответственностью каждой организации.

| Термин | Определение |
|--------|------------|
| **OrgOS** | Организационный runtime на инфраструктуре, которую вы контролируете |
| **OOO** | [OpenOrgOS Operator](/certifications) — эталонная роль для развёртывания |
| **ISO 37000** | Международное руководство по управлению организациями |
| **Самодекларация** | Собственное заявление организации — не аккредитованная сертификация |

ISO 37000 — это **руководство**, а не сертифицируемый стандарт требований вроде ISO 9001. OrgOS делает оценку **операционной и основанной на доказательствах**.

## Последовательность

1. **Развернуть** — OrgOS на своём оборудовании ([руководство по установке](/content/orgos-install-setup))
2. **Подготовить** — правовой статус, структура, юрисдикции, модули
3. **Инициализировать** — `orgos tenant init` пишет скелет цели и черновик ISO 37000
4. **Оценить** — `orgos governance principles status`. Заполнитель mission не считается ready
5. **Заявить** — только человек: `orgos governance principles declare --signatory "…"`

Путь обычно ведёт **OpenOrgOS Operator (OOO)**.

## Темы (иллюстративно)

| Принцип ISO 37000 | Что помогает установить OrgOS |
|--------------------|--------------------------------|
| **Purpose** | Миссия, видение и ценности в бизнес-плане |
| **Value and strategy** | Планы, KPI, бюджетные пороги |
| **Oversight** | События компании, протоколы, Operator Console |
| **Accountability** | Назначенные операторы, RBAC, запрет самоодобрения |
| **Stakeholders** | Советники, реестр управления, IR / Wire |
| **Leadership** | Окончательное человеческое одобрение, домен входа, PassKey |
| **Data and decisions** | YAML как источник истины, analytics, панели |
| **Risk** | Реестр рисков; ISMS при включённом ISO 27001 |
| **Social responsibility** | ESG / экологические нормы при применимости |
| **Viability** | Многолетние планы, долг, жизненный цикл тенанта |

## Объём «готовности к самодекларации»

**В объёме:** рабочая структура и след решений; путь цель → структура → надзор; `orgos governance principles status`.

**Вне объёма:** автоматическая ISO-сертификация; юридическая консультация; ISO 37001 (борьба со взяточничеством) или ISO 37301 (CMS) — отдельные пакеты.
